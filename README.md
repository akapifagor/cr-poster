# CR offers -> Telegram канал

Раз в 30 минут берёт новые офферы Content Rewards (все форматы и ниши) и постит их в канал с твоего аккаунта (юзербот, поэтому работают кастомные эмодзи). Картинка поста - баннер оффера.

## Запуск на GitHub (без VPS), ~10 минут
1. my.telegram.org -> API development tools -> создай приложение, возьми api_id и api_hash.
2. На своём компьютере: `pip install telethon` и `python login.py`. Введи api_id, api_hash, номер и код из Telegram. Скрипт выведет TG_SESSION.
   TG_SESSION = полный доступ к твоему аккаунту. Никому не отправляй, храни только в GitHub Secrets.
3. Создай ПРИВАТНЫЙ репозиторий на GitHub и загрузи туда все файлы этой папки (включая .github/workflows/post.yml).
4. Репозиторий -> Settings -> Secrets and variables -> Actions -> New repository secret: TG_API_ID, TG_API_HASH, TG_SESSION.
5. В config.json впиши "channel": "@твой_канал" (твой аккаунт должен быть админом с правом публикации).
6. Actions -> "CR offers -> Telegram" -> Run workflow. Первый запуск запомнит все текущие офферы и запостит 3 последних для проверки (first_run_post). Дальше сам каждые 30 минут.

## Кастомные эмодзи соцсетей
Отправь себе в Избранное одно сообщение с премиум-эмодзи в порядке X, TikTok, Instagram, YouTube и запусти `python emoji_ids.py`. Полученные id вставь в config.json -> platform_emoji. Пока пусто - стоят обычные 𝕏 🎵 📸 ▶️.

## Рефка
Когда CR одобрит партнёрку, впиши в config.json "link_template", например
"https://contentrewards.com/c/campaigns/{id}?ref=КОД" (формат возьмём из твоей партнёрской ссылки).

## Что в посте
Название, ниша (категории CR на русском, гемблинг помечается 18+), формат (клиппинг / UGC с лицом / без лица...), готовый футаж (определяется по описанию оффера - это оценка, точный список материалов в брифе), ставки по каждой соцсети с лимитом за пост, бюджет и % потраченного, гео-ставки, по заявке или нет, ссылка.

Примечание: GitHub cron может запускаться с опозданием на 5-15 минут в часы нагрузки.

## Нейросеть для ниш и футажа (Gemini, бесплатно)
1. aistudio.google.com -> Get API key -> создай ключ.
2. GitHub Secrets: добавь GEMINI_API_KEY.
3. Actions -> "AI test (no posting)" -> Run workflow. Скрипт прогонит 50 офферов с ручной разметкой и в конце лога напишет точность AI и правил. Ничего не постит.
Если ключа нет или лимит исчерпан, пост собирается по правилам (как раньше).
Модель меняется в config.json -> ai_model.
